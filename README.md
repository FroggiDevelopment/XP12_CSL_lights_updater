When moving on to XP 12 I realized that the somewhat older CSL models from Bluebell and X-CSL lack lights during daylight.

Now, with some updates of XP 12, it is partially better, but still not as good as the XP 12 native lighting can be.

So I wrote this program to convert those CSL models to the new XP 12 lighting.
During the development of this program I added some extra tuning (flashing beacons, varying flash sequences for beacons and strobes).
I also (finally) added a GUI from V1.4.0 on.

This is still work in progress. I'd like to add some more support for the custom models, which are not part of the Bluebell and X-CSL packages.

This program requires Python 3.10 as minimum. It is testes up to Python 3.13.

GUI's included are for Windows (tested on 10 and 11), Linux(tested on Mint 21.3) and MacOS (tested on Big Sur).
